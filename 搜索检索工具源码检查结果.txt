二、重点展开：web_search 内部真实 Provider 链
--------------------------------------------------------------------------------

源码 web_search.py:231-255，实际降级逻辑：

  _search_doubao() ──空列表──▶ _search_tavily() ──空列表──▶ _search_brave()

① 豆包搜索（火山引擎 feedcoopapi）  web_search.py:26
   请求：POST https://open.feedcoopapi.com/search_api/web_search
   Header：Authorization: Bearer <key>
   Body：{ Query: query[:100], SearchType: "web", Count: 5,
           Filter: { NeedUrl: true }, QueryControl: { QueryRewrite: false } }
   取 Result.WebResults[] 的 Title/Url/Summary（Summary 截 500 字喂给 LLM）
   局限：Query 截断 100 字符；官方文档注明不支持多词搜索；
         Filter.Sites/BlockHosts（豆包本身支持）代码未暴露

② Tavily  web_search.py:65
   请求：TavilyClient(api_key).search(search_depth="basic", max_results=5,
          include_answer=True)
   取 answer 摘要 + results[]（content 截 400）
   局限：include_domains/exclude_domains 参数未传

③ Brave  web_search.py:112
   请求：GET https://api.search.brave.com/res/v1/web/search
   Header：X-Subscription-Token；search_lang=zh-hans
   取 web.results[] 的 title/url/description
   局限：key 未配置（.env 无 BRAVE_API_KEY），实际链条只走到 Tavily

【全链关键局限】
- 降级条件是"返回空列表"才切下一个源：任何一个源抛异常（网络错、401、
  限流）会直接进 except 返回"搜索失败"，不会自动降级
- 无分页、无结果缓存、TIMEOUT=15s 硬编码、单次最多 5~6 条

四、各工具主要局限（源码层面）
--------------------------------------------------------------------------------

1. web_search
   - 异常不降级（只有空结果才降级）
   - 无 site/domain 结构化参数（豆包 Filter.Sites、Tavily include_domains
     均未暴露，只能靠 query 里写 site: 语法，但豆包对 site: 支持有限）
   - 豆包 Query 截断 100 字符、官方文档注明不支持多词搜索

2. web_search_overseas
   - hl 固定 zh-cn，英文内容可能偏中文偏好
   - 只取 organic 列表，不使用 news/knowledge_graph/scholar 等分区

3. web_search_deep
   - Exa 的 includeDomains/excludeDomains、numResults 未暴露（硬编码 5）
   - 当前 EXA_API_KEY 未配置，实际调用返回"搜索失败：EXA_API_KEY 未配置"

4. search_github_code
   - 只返回文件元数据（repo/path/stars），不含文件内容，要看代码需二次 fetch
   - Code Search API 认证后限速 30 次/分
   - 只索引公开仓库的默认分支，私有内容不可搜

5. vector_search
   - top_k=3、阈值 distance<=0.75 硬编码（L2 距离阈值较严格，可能过滤掉
     部分相关片段）
   - 单次查询一次 embedding 调用
   - 依赖 Supabase 连通（历史存在 DNS 解析失败）
   - 分块逻辑由调用方负责，工具本身不做分块
